# AI-Aion (AI-永恒计划)

> **愿景**：构建一个超越单体智能的、可自我进化的数字文明沙盒，为现实世界的复杂决策提供“上帝视角”的预演。

## 🌌 项目核心：三位一体 (The Triad)

AI-Aion 不再仅仅是一个对话机器人，而是一个吞噬数亿 Token 的 **演算引擎**。

### 1. 灵识层 (The Logos Layer) - 专家集群
*   **众神议事 (Gods Assembly)**：通过 Identity Imprinting 实时生成成千上万个立场迥异的 Agent。
*   **递归辩论 (Recursive Debate)**：让 Agent 在数字荒野中进行深度的逻辑博弈。

### 2. 载体层 (The Aether Layer) - 万向环境
*   **超长时序 RAG (Temporal RAG)**：1M+ 上下文感知，泵入数十年行业积淀。
*   **因果沙盒 (Causal Sandbox)**：模拟现实世界的连锁反应，观测蝴蝶效应。

### 3. 演化层 (The Chronos Layer) - 时间加速
*   **代际演化 (Generational Evolution)**：自我批判与自我迭代，追逐逻辑奇点。
*   **大梦演算 (Great Dream Computing)**：并行运行 100+ 平行世界，锁定唯一的“绝对路径”。

## 🛠 技术栈

*   **后端核心**：Java 21 (虚拟线程) + Spring Cloud Alibaba + MyBatis Plus
*   **存储底座**：TiDB (海量结构化数据) + Milvus (向量记忆池)
*   **前端交互**：Vue 3 + TypeScript + Three.js (3D 逻辑森林)
*   **辅助脚本**：Python 3.10+ (极简博弈模拟)

---

## 🚀 快速启动

### 1. 后端启动
```bash
mvn clean install
cd aion-logos && mvn spring-boot:run
```

### 2. 前端启动
```bash
cd aion-ui
npm install
npm run dev
```

### 3. Python 辅助脚本运行
```bash
cd python_scripts
pip install -r requirements.txt
python debate_sim.py
```
